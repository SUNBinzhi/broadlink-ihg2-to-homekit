# 01 · 硬件与系统识别

## 1. 这类系统长什么样

开发商预装的博联全屋智能，通常由三部分组成：

```
┌─────────────────────────────────────────────────────────┐
│  云端（博联 / CloudThink）                                │
│  · houseproxy 接口（小度 DuerOS 协议）                     │
│  · 设备清单、场景、用户会话                                │
└───────────────▲─────────────────────────────────────────┘
                │ HTTPS
┌───────────────┴─────────────────────────────────────────┐
│  微信小程序「全屋智控」                                    │
└───────────────▲─────────────────────────────────────────┘
                │ 局域网
┌───────────────┴─────────────────────────────────────────┐
│  IHG2 中控（型号 IC.IHG2，OpenWrt 系统）                  │
│  · 局域网 IP 通常由路由器 DHCP 分配                        │
│  · 对外只开 80 端口（LuCI 后台，有密码）                   │
└───────┬───────────────────────┬─────────────────────────┘
        │ 485 / 私有总线          │ 网口或 BLE
┌───────▼────────┐      ┌───────▼──────────────┐
│ 灯 / 窗帘 / 新风 │      │ 空调网关（如中弘 B18L）│
│ 智能面板         │      │ 再经 485 接空调内机    │
└────────────────┘      └──────────────────────┘
```

### 关键认知

- **控制入口在云端，不在网关**。小程序 → 博联云 → 网关，所以断网时小程序不可用，但墙上面板仍可用。
- **IHG2 的本地协议是锁定的**。局域网认证会失败（设备返回 `locked`），不要在这上面浪费时间。
- **空调可能走独立网关**。有的项目是网口版（TCP 9999），有的是 BLE 版（只能近场配置），需要单独确认。

## 2. 怎么确认自己家是不是同款

按顺序做，命中越多越确定：

- [ ] 网关背面/底部标签写着 `IC.IHG2` 或 `IHG2`
- [ ] 微信里控制用的小程序叫「**全屋智控**」
- [ ] 小程序「网关配置」里能看到「空调网关」之类字样
- [ ] 路由器后台能扫到一台 MAC 前缀属于 `e8:16:56`（博联）的设备
- [ ] 这台设备开 80 端口，访问会跳到 LuCI 登录页

如果只是「博联」但型号不同，协议可能不一样，抓包后以实际请求为准。

## 3. 本文用到的硬件

| 用途 | 最低配置 | 说明 |
|---|---|---|
| 抓包 | 任意电脑 | macOS / Windows 都行，装电脑版微信 |
| HA 主机 | NAS（Docker）/ 小主机 / 树莓派 | 建议 2GB 内存以上，7×24 开机 |
| 语音 | iPhone / iPad | 家庭 App |
| 远程（可选） | Apple TV / HomePod | 家庭中枢 |
| 调试（可选） | 安卓手机 | 抓 BLE 日志用 |

| 项 | 费用 |
|---|---|
| 抓包（已有电脑） | 0 |
| HA（已有 NAS） | 0 |
| mitmproxy / HACS / 集成 | 0（开源） |
| Apple TV / HomePod（可选） | 1000+ |

**这套方案不需要买任何新的智能硬件**——除非你想替换执行层（见 06 篇）。

## 5. 开始之前的三条建议

1. **先备份**：抓包前把网关 web 后台密码、小程序设备列表截图存一份。
2. **先只读**：第一次抓包只看「查询状态」，不要急着发控制指令。
3. **准备一台常开机器**：HA 必须 7×24 运行，不要用会休眠的笔记本。
