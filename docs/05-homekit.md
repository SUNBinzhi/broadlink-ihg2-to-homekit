# 05 · HomeKit / Siri

## 1. 添加桥接

HA → 设置 → 设备与服务 → 添加集成 → **HomeKit Bridge** → 选 `bridge` 模式。

关键设置：

- **包含模式**：选「包含（include）」，然后**逐个勾选**要暴露的实体
- 不要用「按域全收」——会把小米插座、WOL 开关等无关设备也塞进家庭 App
- 保存后会生成二维码，用 iPhone「家庭」App 扫码

> 桥接的配对关系与筛选条件无关：**改筛选不会导致重新配对**，但 iOS 需要刷新一次。

## 2. 命名策略（很重要）

家庭 App 里所有配件**默认都落在添加桥接时选的那个房间**。所以：

- 如果房间还没分，先只用一个房间也能凑合，但重名会很难受
- 建议命名带房间前缀：`客厅灯` / `主卧灯` / `客厅空调` / `主卧空调`
- 或者用纯功能名 + 手动分房间：`灯` / `空调`，靠房间区分

**经验**：房间没分好之前，用「房间+功能」命名；分好之后可以简化。

## 3. 房间分配

HomeKit 协议**不含房间信息**，HA 无法替你分房间。只能在手机上：

- 长按配件 → 设置 → 房间 → 选择
- 或者长按拖动到目标房间区域

## 4. 摄氏 / 华氏

如果家庭 App 显示 77° 而不是 25°，不是数据错了：

```
25°C = 77°F
```

HA 发送的是摄氏，iPhone 按系统设置显示。修复：

> 设置 → 通用 → 语言与地区 → **温度** → 摄氏度

## 5. 空调一键开关

HomeKit 的温控配件默认只有模式切换，没有电源按钮。两种做法：

- 在 HA 仪表盘上放一个 `button` / `tile`，`tap_action: toggle`
- 或者直接用 HomeKit 的模式选择（含 Off）

前提是 climate 实体声明了 `TURN_ON` / `TURN_OFF`（见 04 篇第 5 节）。

## 6. 窗帘与灯组

- 窗帘的「位置」就是 `DeltaValue`，HA 的 `cover.set_position` 直接映射
- 灯组是一个虚拟设备，控制它等于一次性控制组内所有灯
- 注意：灯组的状态**不一定反映**单独打开某盏灯，反之亦然

## 7. 推荐的最小配件清单

| 类型 | 数量 | 说明 |
|---|---|---|
| 灯 | 每房间 1 个灯组 | 不要一上来暴露 20 路灯 |
| 空调 | 每房间 1 台 | |
| 窗帘 | 每扇 1 个 | |
| 新风 | 每房间 1 个 | |
| 传感器 | 温度/湿度 | 可选 |

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 家庭 App 里出现重复配件 | 旧配件残留，杀掉 App 重开；仍不行则移除配件 |
| 新配件没出现 | 重启 HA 或重载 HomeKit Bridge |
| 名称没更新 | 强制刷新家庭 App；HA 侧改名后桥接会同步 |
| 全部不可用 | 检查 HA 会话是否过期（见 06 篇） |
